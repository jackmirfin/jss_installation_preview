# JSS Installation · Instant Estimate preview

One standalone page, focused exclusively on the bathroom estimate journey.

## View locally

Open `index.html`, or run a static server in this folder:

```text
python -m http.server 9001 --bind 127.0.0.1
```

Then visit `http://localhost:9001/`.

## Vercel

Deploy this folder as a static project. Select **Other** as the framework,
leave the build command blank and use the project root as the output directory.
`index.html` is the root page. No dependencies, backend or environment variables are required.

## Preview boundary

- Guided bathroom journey: project intention, approximate size, features, optional notes.
- Detailed bathroom journey: six expandable trade sections and an option to delegate uncertain details to JSS.
- Back navigation preserves answers in the open document.
- Other project types explicitly explain that this preview focuses on bathrooms.
- Contact details are optional in this concept and are cleared when the consultation demonstration finishes.
- No pricing has been invented or calculated. The result explains where JSS's existing pricing logic would be connected.
- No form submission, emails, analytics, tracking or persistent storage. Answers exist only in the current document and disappear on reload.
- Images and fonts are local, so browsing the preview does not request third-party assets.
- Telephone and website links are ordinary explicit links to the real business.
